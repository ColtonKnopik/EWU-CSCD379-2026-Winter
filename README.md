## About The Game

**Starfall Dominion** is an intense turn-based tactical combat game set on a hexagonal battlefield. Command your forces, capture strategic points, and eliminate your enemies in this fast-paced strategy showdown. Built with cutting-edge web technologies, Starfall Dominion delivers a smooth, cinematic gaming experience right in your browser.

### Key Features

- **Tactical Hex-Grid Combat** - Master the art of hexagonal warfare
- **Local 1v1 PvP** - Face off against a friend on the same device
- **Diverse Unit Types** - Deploy Captains, Marines, Berserkers, and specialized units
- **Dynamic Economy** - Manage gold and income to build your army
- **Capture Points** - Control flags to secure victory
- **Cinematic Effects** - Experience explosive combat with stunning visual feedback
- **Real-Time Combat Log** - Track every move, attack, and elimination
- **Customizable Settings** - Adjust animation speed, sound, and grid visibility

##  Gameplay

### How To Win

- **Eliminate Enemy Captain** - Take out the opposing commander
- **Capture All Flags** - Control strategic points across the battlefield
- **Force Surrender** - Break your opponent's will to fight

### Game Mechanics

1. **Placement** - Deploy your captain in your deployment zone
2. **Recruitment** - Purchase units from your spawn points
3. **Combat** - Move, attack, and capture objectives
4. **Victory** - Achieve one of the win conditions

##  Getting Started

### Prerequisites

- Node.js 20.x or higher
- npm, pnpm, yarn, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/ColtonKnopik/EWU-CSCD379-2026-Winter.git
cd Starfall-Dominion

# Install dependencies
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Navigate to `http://localhost:3000` and start playing!

### Build for Production

```bash
npm run build
npm run preview
```

### Run Tests

```bash
npm test
```

## Controls

- **Click to Select** - Click a unit to select it
- **Click to Move** - Click a highlighted cell to move
- **Click to Attack** - Click an enemy in range to attack
- **Shop Button** - Open unit shop at spawn points
- **End Turn** - Pass control to the other player
